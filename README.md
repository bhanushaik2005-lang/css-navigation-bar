Description

This project demonstrates how to create a simple and responsive navigation bar using HTML and CSS.

The navigation bar contains links for Home, About, Services, Portfolio, and Contact.

Features
Simple navigation bar
CSS Flexbox layout
Hover effects
Responsive design
Logo section
Navigation links
Mobile-friendly layout

HTML5
CSS3

How to Run
Download or clone the repository.
Open the index.html file.
Open it in any web browser.
Hover over the navigation links to see the hover effect.
Resize the browser to see the responsive design.
